# Fish Time — Estação Meteorológica para Pescadores

Estação meteorológica inteligente desenvolvida para monitorar o clima em tempo real e indicar condições seguras para pesca.

Projeto acadêmico desenvolvido em grupo, do curso de **Ciência da Computação — UNIP**.

---
## ⚙️ O que o sistema faz

* **Mede:** Temperatura, Umidade e Pressão Atmosférica.
* **Classifica:** 
  * 🟢 **Pesca Ideal** (condições favoráveis)
  * 🟡 **Pescar com Cautela** (atenção a mudanças)
  * 🔴 **Não Pescar** (risco de temporais/extremos)
* **Exibe:** Dashboard interativo em tempo real com gráficos e histórico.

---

## 🛠️ Tecnologias

* **Hardware:** ESP32, Sensor AHT21 (Temperatura/Umidade) e Sensor BMP280 (Pressão).
* **Software:** C++ (ESP32), Python (Streamlit, Pandas e Plotly).
